# 670710332-swreqspec

## สิ่งที่ได้เรียนรู้จากการเขียนโค้ด

1. **test จาก AC ช่วยหาบั๊ก** test กรณีที่นั่งเหลือ 0 ไม่ผ่าน เพราะโค้ดเขียน `remaining < 0` แทน `<= 0` จึงได้รู้ว่าค่าขอบต้องมี test ของตัวเองเสมอ
2. **ห้ามแก้ test ให้ผ่าน** ถ้า test ไม่ผ่าน ต้องหาว่าโค้ดผิดหรือ AC ผิด ครั้งนี้โค้ดผิด จึงแก้ที่โค้ดโดยไม่แตะ test
3. **test ผ่านไม่ได้แปลว่าถูก spec** ยังต้องอ่านโค้ดของ AI เทียบกับ spec เพราะเจอว่า AI เขียนเลขบัตรประชาชนลง log และเพิ่ม API ยกเลิกการจองที่ spec ไม่ได้สั่ง
